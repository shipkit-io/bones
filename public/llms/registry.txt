# ShipKit: Component Registry

36 installable items in the shadcn registry format. Start from Bones and add features one at a time.

Docs: https://shipkit.io/docs/features/registry

## Install an Item

1. Add the registry to components.json:

```json
{
  "registries": {
    "@shipkit": "https://shipkit.io/r/{name}.json"
  }
}
```

2. Install:

```
npx shadcn add @shipkit/auth
```

Or by URL: `npx shadcn add https://shipkit.io/r/auth.json`

## How It Works

- Source: registry.json in the ShipKit repo (Bones has none)
- Build: `bun run build:registry` runs `npx shadcn build` and writes public/r/*.json
- Files install to their original paths, so blocks land under src/app/(app)/
- Internal dependencies use the @shipkit prefix (cn, routes-config, features-config)
- Each item embeds full file contents in its JSON
